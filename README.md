> A high-performance, dark cyberpunk-themed portfolio showcasing cybersecurity engineering, penetration testing, threat research, and software development capabilities.

---

## 🚀 Key Features

- **🌐 3D Interactive Hero Canvas:** Built with Three.js / React Three Fiber delivering fluid orbital cyber-surveillance visuals.
- **🔍 Deep-Dive Security Dossier Modal:** Detailed breakdowns for each project covering threat models, OWASP attack vectors, architecture layers, and mitigations.
- **📄 Interactive Resume & Google Drive Integration:** In-browser PDF preview directly synced with Google Drive, printable CSS stylesheet, and direct download links.
- **🔊 Native Web Audio Synthesizer (SFX):** Zero-asset, zero-latency Web Audio API sound engine providing responsive mechanical clicks, hover frequencies, and modal chimes with persistent mute control.
- **✉️ Smart Contact & Dispatch Engine:** One-click direct dispatch to **Gmail Web** with pre-filled candidate inquiry templates (solves modern browser `mailto` issues on Windows/macOS), plus Outlook Web and direct clipboard copy.
- **📱 Ultra-Responsive & 0 Horizontal Scroll:** Strict viewport constraints, smooth Lenis/Framer Motion animations, and GSAP-driven interactive cards.

## 🛠️ Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Library:** [React 19](https://react.dev/)

- **3D & Animation:** [Three.js](https://threejs.org/), [React Three Fiber](https://r3f.docs.pmnd.rs/), [GSAP](https://gsap.com/), [Framer Motion](https://www.framer.com/motion/)

- **Audio:** Native Web Audio API (`AudioContext`)
- **Hosting:** [Vercel](https://vercel.com/)

## 📦 Getting Started

### Prerequisites

- Node.js 18+ installed
- npm, yarn, or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/mohd-rehan13/portfolio.git
cd portfolio/next-portfolio

# Install dependencies
npm install

# Run the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

### Building for Production

```bash
npm run build
npm run start
```

## 🚀 One-Click Deploy to Vercel

1. Push this repository to your GitHub account (`https://github.com/mohd-rehan13/<repo-name>`).
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Import your GitHub repository.
4. If your Next.js project is located in `next-portfolio`, set the **Root Directory** in Vercel project settings to `next-portfolio`.
5. Click **Deploy**. Vercel will build and assign a production URL (e.g. `https://mohammad-rehan.vercel.app`) with automatic SSL and continuous deployment!
